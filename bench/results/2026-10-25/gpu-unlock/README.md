# gpu_unlock 前后的服务性能（2026-10-25）

同一张改装 48 GB RTX 4090、同一组合（Strata 0.2.2 + engine 0.1.47、IQ3_S、262144 上下文）、
同一个 `bench/run_matrix.py`、同 seed、同 5 个 cell（P1K/P8K/P32K/D1K/D32K）。

- **stock**：久跑引擎（3 天）单次采样，测量时桌面会话存在。
- **解锁**：冷启动解锁后新起引擎，连跑 4 遍；第 1 遍为冷态（明显偏慢），取**后 3 遍中位数**。
  解锁侧测量前已停掉桌面会话（`lightdm` inactive、无进程占 `/dev/nvidia*`）。

原始数字：`summary.csv`（stock / 解锁中位 / 解锁区间 / 比值 / 该行是否可作判据）。

## 判据

- **prefill 可判**：同一侧重复跑波动 1–4%；8K 0.983×、32K 0.993×，两个方向都在 1–2% 内 → 无收益。
- **decode 不可判**：同一侧波动 ±12%，大于任何可能效应（D1K 1.118×、D32K 0.941× 即为抖动）。
- **P1K 不可归因**：0.883× 与两侧引擎的专家 RAM 驻留差异混淆（久跑引擎被真实流量暖过）。

结论与原因见 [docs/GPU-UNLOCK.md](../../../docs/GPU-UNLOCK.md)：量化路径不消费
「FP16/BF16 输入 + FP32 累加」的 2×；同一批测试里 `dp4a`、`s8/s32` 不变即为证据。
